# 对位猜数字 · 双人在线对战

移动端优先的双人实时网页小游戏。双方各自设置秘密数字，房主选择 3、4 或 5 位模式，掷骰决定先手，再轮流猜对方密码；只反馈数字与位置同时正确的个数。视觉采用樱花粉主题与纯 SVG「粉团子」IP。

## 本地运行

```bash
npm ci
npm start
```

打开 `http://localhost:3000`。同一局域网内的手机可访问运行电脑的局域网 IP 和端口。请勿使用 `file://` 直接打开 HTML；实时对战需要 Node.js 服务。

## 对局流程

1. 昵称限 1–4 个汉字、英文字母或数字；可留空使用「玩家A / 玩家B」。第二位与第一位同名时自动加 `2`。
2. 创建房间后分享 6 位字母数字房间码或链接。房主可在准备阶段选择 3、4 或 5 位模式；切换模式会清空双方已锁定的密码。
3. 双方各自设置并锁定密码（0–9，可重复、可 0 开头）；双方锁定后掷骰决定先手，同点自动重掷。
4. 玩家轮流提交完整猜测。每回合 60 秒，超时判当前玩家弃权；服务器仅返回对位命中数，不提示数字是否出现在其他位置。
5. 常规胜方累计 1 胜。败方可发起尊严之战，获胜方同意后败方最多再猜两次；任一次全中则本局改判平局。
6. 结算后公开双方密码，显示比分与猜测次数，可保存/分享 PNG 战绩卡。双方均选择「再来一局」后保留房间、昵称和累计比分，重置密码与历史。

## 房间、隐私与断线

- 房间最多 2 人；新房间码为 6 位并排除易混字符。
- 带 `?room=房间码` 的邀请链接会预填房间码。若本地没有昵称，页面会提示先填写昵称再加入。
- 刷新后可用浏览器本地重连令牌恢复座位；断线后保留 120 秒并暂停对局计时，超时后清理离线座位。
- 密码不会进入对局状态广播；仅在最终结算阶段公开。房间无人在线 30 分钟后清理，房间状态在进程内存中，服务重启会清空。
- 尊严之战邀请等待 25 秒，未回应按拒绝处理。预设表情设有服务端频率限制。

## 公网部署（Render）

仓库根目录包含 `render.yaml`。将项目推送到 GitHub 后，在 Render 通过 **New → Blueprint** 连接仓库并部署。服务监听 Render 提供的 `PORT`，并提供 `/healthz` 健康检查。免费实例可能休眠或重启；需要持久房间时应改用 Redis 等外部存储。

## 技术栈与检查

- Node.js、Express、Socket.IO；网页通过同源 Socket.IO 实时同步。
- 输入由前后端双重校验；前端不计算命中、比分或胜负。
- `npm run check` 检查服务端与外部浏览器脚本语法。
