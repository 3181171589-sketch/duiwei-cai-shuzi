# 对位猜数字 · 双人在线对战

一个手机优先的实时网页小游戏。前端页面集中在 `public/index.html`，房间、密码、骰子、回合、比分和胜负由 Node.js + Socket.IO 服务端统一管理。

## 本地运行

```bash
npm ci
npm start
```

访问 `http://localhost:3000`。要让同一局域网的手机测试，从手机访问运行电脑的局域网 IP 和端口。

## 对局流程

1. 创建房间获得 6 位数字房间号，或输入 4–6 位数字房间号加入；链接会携带房间号。
2. 双方分别设置并锁定三位秘密数字（允许重复和前导零）。
3. 双方各掷一次骰子，点数较大者先手；平局后重新掷骰。
4. 双方轮流猜对方密码。只统计数字与位置同时正确的个数，不提示具体位置。
5. 三位全部命中后，服务端宣布胜者并更新比分。双方确认后可在原房间再来一局，比分保留。

## 房间与断线

- 房间最多两人，房间码为 4–6 位数字（新建房间默认 6 位）。
- 房间无人在线 30 分钟后清理。
- 玩家断线后保留座位 90 秒；期间重连可以继续，游戏进行中暂停等待。超时后本局终止并等待新对手。
- 房间状态保存在内存中；服务进程重启后房间会清空。适合单实例部署。

## 部署到公网（Render）

1. 将此文件夹内容推送到你有权限的 GitHub 仓库（确保 `package.json`、`server.js`、`render.yaml` 位于仓库根目录）。
2. 在 Render 选择 **New → Blueprint**，连接仓库并应用 `render.yaml`。
3. 部署成功后，用 Render 提供的 HTTPS 地址访问游戏。创建房间后复制链接分享给好友，手机和电脑均可通过该链接加入。

`index.html` 虽为单文件页面，但它依赖同源的 `/socket.io/socket.io.js` 和 Node.js Socket.IO 服务端，必须通过部署好的网站地址访问；直接双击用 `file://` 打开不能联网对战。免费实例可能休眠，唤醒或服务重启后内存房间可能清空。

## 技术说明

- 服务监听平台提供的 `PORT`，绑定 `0.0.0.0` 并提供 `/healthz` 健康检查。
- Socket.IO 与网页共用同一 Node.js 服务，优先使用 WebSocket，并支持网络重连。
- 不要部署到纯静态托管；在线对战依赖 Node.js 服务端。
